# フォルダ配置の判断 — 2026-09-15

- 決定主体: 入口にはREADME・AGENTS等を置き、本体を下位へ分類する方針は依頼者の指定。具体的な分類名と移動先は実装者判断。
- 決定: 基盤の分類名を小文字英語、案件内を01_raw〜09_skillsへ揃える。共通契約はcontext/docs、一覧はbrain/indexes、未分類項目はbrain/inbox、目的・説明書は案件03_context/docs、判断記録は07_logs/decisionsへ置く。
- 理由: 入口で読むべき案内と文書本体が混在すると、必要な情報の種類と所在が分かりにくい。新規案件を作った時点で同じ構造になるよう、作成処理と点検も変更する。
- 採用しなかった案: 空フォルダの先行作成、Git設定やパッケージ構造の機械的な移動。用途のない階層や実行障害を増やすため採用しない。
- 根拠: 今回の整理依頼、[配置ガイド](../../brain/docs/folder-layout.md)、[移動対応表](../../brain/config/layout-migration-2026-09-15.json)。
- 適用範囲: 共通基盤と案件の入口。原本、配布済みパッケージ、アプリ内部はそれぞれの構造を保全する。
- 見直し条件: 新しいツールが配置を要求する場合は、理由と検証を伴って例外を登録する。
