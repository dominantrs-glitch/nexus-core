# AIから利用する

## 読み取りに必要な条件

AIがリポジトリ内のファイルを取得できる必要があります。ブラウズ、GitHub接続、ローカルファイル読取、添付のいずれかを用意します。
GitHubのトップページだけが取得できても、各ファイルを読んだことにはなりません。
自動取得できない場合はREADME、AGENTS、brain/README、brain/AGENTS、関連Projectを渡し、追加の根拠を必要時に渡します。
保存には別途ファイル書込権限が必要です。チャットが保存内容を提案しただけでは保存完了ではありません。

## 作業の依頼例

読み始め：このリポジトリのREADMEとAGENTSの順に読み、構造と使い方を説明してください。取得したファイルを示してください。

再開：brain/projects/対象.mdを読んで、現在採用されている判断、次の行動、不足している情報を示してください。

記録：この判断と理由を保存してください。案件内の判断か、案件をまたいで使うMemoryかを運用規則に沿って選んでください。

評価：brain/retrieval_eval/README.mdの質問に、リポジトリの根拠だけで答えてください。読めないファイルは推測せず報告してください。

## 環境ごとの限界

AGENTS.mdが自動で読まれるか、継続会話で指示が保持されるか、GitHub接続が書込可能かは利用環境次第です。
この公開版は特定のAIアプリの設定を変更しません。起動・連携の専用実装は同梱していません。
新しいAI環境へ移した時は、架空案件で読み取り・保存・再開を再確認してください。
