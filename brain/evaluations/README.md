# リポジトリだけで理解できるかの評価

この説明と架空のsample-reportだけを、初見の人または新しいAI会話へ渡して評価します。
会話履歴・個人環境の説明は渡さず、必要なリポジトリ内ファイルの取得だけを許可します。

## 質問

1. この仕組みは何を解決し、何を自動化していないか。
2. 現在地、判断理由、再利用Memory、完成物はどこへ保存するか。
3. 新規案件はどう作るか。必要な実行環境は何か。
4. sample-reportの現在地、次の作業、テキスト形式を選んだ理由は何か。
5. sample-reportで確認済みと未確認なのは何か。本人の実運用で成功した例か。
6. 記録の形式検査が通れば、全成果物が記録済みと判断できるか。
7. 新しい会話で再開するには何を読めばよいか。
8. 個人の実記録を保存する前に、自分のコピーで何を設定するか。

## 実操作

チュートリアルだけを見てmy-first-projectを作成し、Current/Nextを更新してNOWを再生成する。
作業を中断し、新しい会話でProjectから再開する。未確認を勝手にPASSや本人確認済みへ変えていないか確認する。

## 採点

回答者は根拠ファイルを併記する。評価者は[採点用の根拠](expected.md)で照合する。
各質問を、根拠付きで一致／不足／誤り／資料取得不可の4種類で記録する。
質問に正答したこと、実操作できたこと、日常運用で続けられたことは別に報告する。
自己点検や固定文字列の検査を第三者AIの理解試験と呼ばない。
結果には日付、版、利用環境、渡したファイル、回答、根拠、未確認を記録する。公開時は実際の個人情報を含めない。
