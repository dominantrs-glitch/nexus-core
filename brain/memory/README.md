# Memory

この公開版に個人のMemoryはありません。[形式](../templates/records/memory.md.template)を使い、私用コピーで本人が明示した記録を月別ファイルへ保存します。
typeはFACT / DECISION / LESSON / HYPOTHESIS、statusはactive / superseded、sourceはuser-confirmed / verified-source / AI-hypothesis。
IDはM-YYYYMMDD-NNN。既存IDを検索して重複を避けます。変更時は旧項目をsupersededにして、新項目のsupersedesに旧IDを指定します。
公開リポジトリへの実記録の追加は公開になります。日常運用は非公開コピーで行ってください。
